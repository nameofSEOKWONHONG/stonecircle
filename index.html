포스트잇 메모 창

메모마다 독립 창으로 띄우고 서식·표·이미지를 편집합니다. 입력을 멈추면 3초 뒤 자동 저장됩니다.

  • 맨 위 고정, 숨기기, 메모·화면 가장자리에 붙이기
  • 위치·크기·배율을 기억해 다음 실행에 복원

메모 일정 알림

특정일·매일·매주 시각을 정하면 그때 메모가 다른 창 위로 떠서 알려 줍니다.

메모·문서로 답하는 AI 채팅

저장한 메모와 로컬 폴더·OneDrive·Google Drive 문서를 AI가 직접 검색하고 읽어 답합니다.

  • 텍스트·Word·Excel·Google 문서와 스프레드시트
  • 답변마다 근거 표시, 메모 링크로 원문 열기
  • 필요하면 웹 검색, 답변을 바로 메모로 저장

Workflow

질문·문서·인터넷 검색·지정한 웹 페이지를 묶어 두면, 정한 시각에 AI가 자료를 모아 정리하고 새 메모로 알려 줍니다.

AI Paste

AI 채팅 사이트에 붙여넣는 순간 주민등록번호·카드 번호·전화번호·이메일·API 키·비밀번호를 가립니다.

  • 붙여넣는 내용은 PC 안에서만 검사
  • 사번 같은 나만의 패턴, AI가 정규식 작성

회의록

마이크와 시스템 소리를 함께 녹음하고, PC에서 Whisper로 받아 적은 뒤 AI가 요약·결정·할 일로 정리합니다.

  1. 녹음마이크 + 시스템 소리를 한 파일로
  2. 로컬 전사Whisper가 PC 안에서 받아 적기, 오디오는 밖으로 나가지 않음
  3. AI 회의록요약 · 논의 · 결정 · 할 일 · 미해결
  4. 메모로 저장확인·수정 후 메모에 보관

두 앱의 공통 원칙

내 데이터는 내 PC에

StoneCircle 앱은 별도 회원 가입이나 개발자 서버 없이 동작합니다.

로컬 저장

라이브러리, 메모, 대화 기록, 설정은 PC의 로컬 데이터베이스에 저장하며 개발자 서버로 보내지 않습니다.

내가 고른 곳에만 연결

AI와 클라우드는 사용자가 직접 설정한 서비스에만 연결합니다. 요청에 필요한 내용만 그 서비스로 보냅니다.

키와 토큰은 암호화

API 키와 로그인 토큰은 Windows 데이터 보호(DPAPI)로 암호화해 현재 Windows 사용자만 풀 수 있습니다.

궁금한 점

AI 없이도 쓸 수 있나요?

네. MUZ의 재생·녹화·캡처·압축·편집과 YUMO의 메모·일정 알림·검색·AI Paste·녹음·전사는 AI 연결 없이 동작합니다. AI 채팅, Workflow, AI 회의록, MUZ AI는 AI 연결이 필요합니다.

어떤 AI를 연결할 수 있나요?

OpenAI, Azure OpenAI, Anthropic Claude, Google Gemini, Ollama(로컬)를 지원합니다. 사용자가 발급받은 키나 직접 띄운 로컬 서버를 연결합니다.

AI Paste는 붙여넣는 내용을 AI로 보내나요?

아니요. 붙여넣는 내용은 PC 안에서 정해진 규칙과 사용자 패턴으로만 검사합니다. AI는 사용자가 원할 때 “패턴 설명 → 정규식” 생성에만 쓰며, 이때도 설명과 예시만 보냅니다.

회의 녹음이 외부로 전송되나요?

오디오는 전송하지 않습니다. 전사는 PC에서 Whisper 모델로 처리하며, 네트워크는 처음 모델 파일을 받을 때만 씁니다. AI 회의록을 만들 때는 전사한 텍스트만 선택한 AI로 보냅니다.

MUZ와 YUMO는 데이터를 공유하나요?

아니요. 두 앱은 각자의 데이터 폴더, 계정 연결, 설정을 따로 가집니다.

원본 파일이 바뀌지는 않나요?

MUZ의 압축·편집은 항상 새 파일로 저장합니다. 목록에서 항목을 빼도 원본은 지워지지 않으며, YUMO 데이터 소스는 등록한 문서를 읽기만 합니다.
